# Starline Feature Request File

このファイルには、実際に実装してほしい機能・画面・APIを記載する。

LLMはこの内容をもとにコード生成・設計を行う。

---

## ルール

- 1機能 = 1ブロックで記載する
- できるだけ具体的に書く
- UI / API / DBの要件があれば分けて書く
- 曖昧な表現は禁止（必要なら質問する）

---

## 機能一覧

### 1. 今日の宇宙史機能
- 今日の日付に対応する宇宙イベントを表示する
- NASA APIまたはWikipedia APIを使用
- 画像があれば表示する
- 1日1回更新、DBにキャッシュする
-1. Wikipedia On This Day API（英語）を叩く
-  https://api.wikimedia.org/feed/v1/wikipedia/en/onthisday/events/MM/DD
-2. 取得した events から宇宙関連だけ抽出
-  （space, NASA, planet, launch, satellite などのキーワードで判定）
-3. Google Apps Script で翻訳 API を作成
-4. 抽出した英語説明文を GAS 翻訳 API に投げて日本語化
-5. 翻訳結果をアプリのレスポンスとして返す

### 2. 今日の宇宙画像機能
- 今日の日付に対応する宇宙画像があれば表示する
- 1日1回更新、DBにキャッシュする

---

### 3. 今夜見える星表示
- 現在地に基づき見える惑星・星を表示
- 月齢情報を表示
- OpenWeather APIと連携
- UIはシンプルなカード形式

---

### 4. 太陽系図鑑機能
- 惑星一覧をホーム画面に表示
- タップで詳細画面へ遷移
- Solar System OpenData API使用
- 衛星数・重力・質量など表示

---

### 5. 今日空見た？機能
- ユーザーが空を見たか記録
- 日付ごとに保存
- 連続記録を表示

---

### 6. 空の共有機能（匿名）
- 空の写真投稿
- コメントなし or 一言のみ
- いいね機能なし
- 時系列で表示

---

## 非機能要件

- SNS的な競争要素は入れない
- UIは静かで余白のあるデザイン
- 毎日開きたくなる体験を優先
